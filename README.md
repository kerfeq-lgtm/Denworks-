# Denwork — AI Work Assistant

A dark, cozy, mobile-first work companion for tracking tasks, paychecks, and savings.

## Current milestone
- Task queue with queued / in-progress / done states
- Daily task goal
- Paycheck log with a $25 personal allowance
- Savings estimate based on recorded paychecks
- Local browser storage on this device

## Prototype limitations
The current assistant screen is a placeholder. AI, cloud sync, file imports, message imports, and automated actions are not connected yet. Data is stored locally in this browser and is not cloud-synced.

## Run locally
```bash
npm install
npm run dev
```
